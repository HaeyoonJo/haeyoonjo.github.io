# About this Book

- Book: Build a Machine Learning Platform (From Scratch)
- Authors: Benjamin Tan Wei Hao, Shanoop Padmanabhan, and Varun Mallya

## What It's About

Getting ML models out of the lab and into production is hard. This book shows how to design and build an ML platform from the ground up, so data and operations teams can collaborate, and training and deployment follow a clear structure. The goal is an internal developer platform (IDP) for ML and AI applications.

## Tools we'll Use
- Kubeflow: pipeline orchestration
- MLflow: experiment tracking and model management
- BentoML: model serving
- Evidently: monitoring
- Feast: feature store
- LangChain: LLM-powered systems
- Kubernetes: the foundation everything runs on

## Structure
1. Part 1: Foundations. MLOps basics and building applications on Kubernetes.
2. Part 2: Platform design. Reliable ML systems, pipeline orchestration, productionizing models.
3. Part 3: The ML workflow. Data preparation, training and validation, inference and serving, monitoring and explainability.
4. Part 4: LLMs. Designing and running production LLM-powered systems.
