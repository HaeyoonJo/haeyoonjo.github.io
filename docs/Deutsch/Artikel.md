## Articles – Declension Tables (A2)

**Column order:** Masculine (M) → Neuter (N) → Feminine (F) → Plural (Pl)

### 1. Definite Articles (Bestimmte Artikel)

| Kasus | M (Maskulin) | N (Neutrum) | F (Feminin) | Pl (Plural) |
|---|---|---|---|---|
| **Nominativ** | der | das | die | die |
| **Akkusativ** | den | das | die | die |
| **Dativ** | dem | dem | der | den |
| **Genitiv** | des | des | der | der |

English: **the**

### 2. Indefinite Articles (Unbestimmte Artikel)

| Kasus | M (Maskulin) | N (Neutrum) | F (Feminin) | Pl (Plural) |
|---|---|---|---|---|
| **Nominativ** | ein | ein | eine | — |
| **Akkusativ** | einen | ein | eine | — |
| **Dativ** | einem | einem | einer | — |
| **Genitiv** | eines | eines | einer | — |

English: **a / an**

Note: The indefinite article `ein` has no plural form.

### 3. Demonstrative Articles (Demonstrativartikel: dies-)

| Kasus | M (Maskulin) | N (Neutrum) | F (Feminin) | Pl (Plural) |
|---|---|---|---|---|
| **Nominativ** | dieser | dieses | diese | diese |
| **Akkusativ** | diesen | dieses | diese | diese |
| **Dativ** | diesem | diesem | dieser | diesen |
| **Genitiv** | dieses | dieses | dieser | dieser |

English: **this / that**

### 4. Interrogative Articles (Frageartikel: welch-)

| Kasus | M (Maskulin) | N (Neutrum) | F (Feminin) | Pl (Plural) |
|---|---|---|---|---|
| **Nominativ** | welcher | welches | welche | welche |
| **Akkusativ** | welchen | welches | welche | welche |
| **Dativ** | welchem | welchem | welcher | welchen |

### 5. Quick Comparison – All Four Article Types

| Kasus | M (Maskulin) | N (Neutrum) | F (Feminin) | Pl (Plural) |
|---|---|---|---|---|
| **Nominativ** | der / ein / dieser / welcher | das / ein / dieses / welches | die / eine / diese / welche | die / — / diese / welche |
| **Akkusativ** | den / einen / diesen / welchen | das / ein / dieses / welches | die / eine / diese / welche | die / — / diese / welche |
| **Dativ** | dem / einem / diesem / welchem | dem / einem / diesem / welchem | der / einer / dieser / welcher | den / — / diesen / welchen |
| **Genitiv** | des / eines / dieses / welches | des / eines / dieses / welches | der / einer / dieser / welcher | der / — / dieser / welcher |

**Order inside each cell:**
1. Definite Article (der/die/das)
2. Indefinite Article (ein/eine)
3. Demonstrative Article (dies-)
4. Interrogative Article (welch-)

### 6. Important Grammar Notes

- `der`, `die`, `das` are definite articles.
- `ein`, `eine` are indefinite articles.
- `dies-` is used to point to a specific person or thing.
- `welch-` is used to ask which person or thing.
- `dies-` and `welch-` have the same endings as definite articles.

**Remember:**

| Kasus | Main Question |
|---|---|
| Nominativ | Wer? / Was? |
| Akkusativ | Wen? / Was? |
| Dativ | Wem? |
| Genitiv | Wessen? |

**Learning Tip:** Start by memorizing the definite article table. Then learn `dies-` and `welch-`, because they follow the same declension pattern.
